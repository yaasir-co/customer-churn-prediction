# Customer Churn AI Academy

## What this project teaches
This project is designed as a complete AI/ML-engineering learning environment rather than only a prediction demo.

### Core skills
- Problem framing
- Data validation and EDA
- Preprocessing pipelines
- One-hot encoding
- Standardization
- Logistic regression
- Random forests
- Gradient boosting
- K-nearest neighbors
- Model evaluation
- Probability thresholds
- Feature importance
- Batch inference
- Model serialization
- Deployment
- Monitoring and drift
- Responsible AI
- Interview communication

## Best model in the included synthetic dataset
**Logistic Regression** achieved the highest ROC-AUC on the held-out test split.

This is not a universal statement that the algorithm is always best. Model choice depends on data, cost, interpretability, latency, calibration and business objectives.
