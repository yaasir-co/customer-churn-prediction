# Module 05 — The Models

## Logistic Regression
Models log-odds as a weighted linear combination of features.

Strengths:
- Interpretable
- Fast
- Strong baseline
- Probability output

## Random Forest
An ensemble of decision trees trained with randomness.

Strengths:
- Nonlinear relationships
- Feature interactions
- Robustness

## Gradient Boosting
Builds weak learners sequentially, focusing on earlier mistakes.

Strengths:
- Often strong on structured data
- Captures nonlinear patterns

## K-Nearest Neighbors
Predicts using nearby examples in feature space.

Strengths:
- Easy to understand
- Nonparametric

Weakness:
- Inference can become expensive with large datasets.

## Core lesson
There is no universally best algorithm. Compare candidates on relevant data and objectives.
