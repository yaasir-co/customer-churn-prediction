# Module 10 — MLOps

MLOps applies engineering discipline to machine-learning systems.

## Version
- Code
- Data
- Features
- Models
- Configurations

## Monitor
- Input distributions
- Missingness
- Prediction distribution
- Latency
- Errors
- Accuracy / recall when labels arrive

## Drift
Data drift: input distribution changes.
Concept drift: relationship between features and target changes.

## Retraining
Do not retrain blindly on a timer. Define validation and promotion criteria.
