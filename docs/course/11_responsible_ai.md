# Module 11 — Responsible AI

## Privacy
Use the minimum data necessary and protect personal information.

## Fairness
Evaluate whether performance differs materially between important groups.

## Human oversight
Use risk scores as decision support, not unquestioned automated truth.

## Transparency
Document:
- Intended use
- Data source
- Metrics
- Limitations
- Model version
- Monitoring process

## Security
Protect model endpoints, customer data and logs.
