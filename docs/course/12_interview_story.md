# Module 12 — How to Explain This Project in an Interview

## 60-second version
“I built an end-to-end customer churn classification system. I created a reproducible preprocessing pipeline for numeric and categorical data, trained and compared logistic regression, random forest, gradient boosting and K-nearest-neighbor models, evaluated them using accuracy, precision, recall, F1, ROC-AUC and log loss, and selected the strongest held-out model by ROC-AUC. I then built threshold analysis, explainability, batch inference and a Streamlit deployment. I also documented how the system would evolve into a monitored production architecture.”

## Strong follow-up areas
Be ready to explain:
- Why train/test split comes before fitting preprocessing
- Why accuracy alone is insufficient
- Why thresholds are business decisions
- Why feature importance is not causality
- How model drift would be monitored
- How you would expose the model through an API
